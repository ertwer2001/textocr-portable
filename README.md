# TextOCR 桌機版與網頁版

兩個版本都可將截圖、照片與 PDF 辨識為中英文字，並匯出 Word、Excel、PPT 或 TXT。請選擇適合的使用入口。

| 版本 | 使用入口 | 詳細說明 |
| --- | --- | --- |
| Windows 桌機版 | [下載桌機版 ZIP](https://github.com/ertwer2001/textocr-portable/releases/latest) | [桌機版說明](README-desktop.md) |
| Chrome／Edge 網頁版 | [直接開啟網頁版](https://ertwer2001.github.io/textocr-portable/) | [網頁版說明](docs/README.md) |

桌機版與網頁版獨立維護。網頁版的新功能或修正不代表桌機版 ZIP 已更新；桌機版請以 GitHub Release 附件為準。

兩個版本的圖片及 PDF 辨識皆在本機完成。OCR 可能辨識錯字，版面重建為近似結果，使用前請核對原稿。
