# TextOCR 網頁版

本說明只適用於網頁版。Windows 桌機版有[獨立操作與下載說明](https://github.com/ertwer2001/textocr-portable/blob/main/README-desktop.md)。兩版分開維護；網頁更新不代表桌機版 ZIP 已更新。

以 Chrome／Edge 開啟網站，貼上圖片或加入 PDF，在瀏覽器本機辨識繁簡中文與英文，匯出可編輯 Word、Excel、PowerPoint 與 TXT。無需執行 TextOCR.exe、Office 或輸入 API 金鑰。

## 操作

1. 點「加入圖片／PDF」、拖入檔案，或在頁面空白處按 Ctrl+V 貼上截圖，可連續加入多張。
2. 勾選要處理的頁面，點「辨識選取頁面」。右側文字可直接校對。
3. 選擇「選取頁面」或「全部頁面」，再匯出 Word、Excel、PPT 或文字。未辨識的頁面會先辨識。
4. Word 預設保留版面並建立可編輯文字與表格，保留辨識出的欄寬與合併儲存格；純文字模式便於重新排版。原圖模式明確標示文字不可編輯。
5. 支援的 Chrome／Edge 可選擇並授權儲存資料夾。其他瀏覽器使用一般下載。每次輸出使用新名稱保護既有文件，從下載清單或資料夾開啟檔案。
6. 首次連線後點「準備離線使用」，待下載完成即可在同一瀏覽器離線開啟同一網址。清除瀏覽器快取後需重新準備。

網站的「操作手冊」提供完整說明。關閉或重新整理網頁前請先匯出結果，目前文件不會永久保存在網站。

Excel 截圖可直接貼上後點「匯出 Excel」：辨識格線與文字後建立可編輯儲存格，保留空白欄位、底色、框線、欄寬與列高，版本編號「01」保留為文字。多張截圖可選頁或全部匯出，每個辨識出的表格各建工作表。若原圖的列或欄被截斷，匯出區會提示補完整截圖；無法恢復裁掉的文字、未顯示的資料或原始公式。

## 辨識與版面

文件截圖可貼上後直接匯出 Word；文字依原位置重建，格線表格為 Word 原生儲存格。辨識出的標誌及照片保留圖像。截圖不含原始字型與段落設定，低解析度細字和印章文字仍需校對，無法保證逐像素一致。改成更長的文字後，請再次檢查換行、表格高度與分頁。

延用桌面版三個 PP-OCRv5 mobile ONNX 模型，ONNX Runtime Web 1.30.0 在 Web Worker 推論；OpenCV 4.13.0 與 Clipper 6.4.2 處理圖片、文字框、表格、流程圖與照片。PDF.js 5.6.205 讀取或渲染 PDF；JSZip 3.10.1 打包原生 Office Open XML。

Word 文字框與表格、Excel 儲存格、PPT 文字、表格、辨識出的形狀及有可靠可見數據的圖表可編輯；照片保留為獨立圖片。Word 中的統計圖表目前保留圖像，如需調整圖表資料請匯出 PPT。截圖不能恢復看不到的公式與數據；複雜版面、低解析度文字與圖表需核對。內嵌報表縮圖的儲存格、縮小工程圖或圖表數字無法可靠辨識時，保留原圖並在匯出區列出需核對的區塊，不捏造數值。工程圖的線條與尺寸需原始圖檔才能完整編輯；清晰的原始 PDF 或表格截圖可得到較完整的可編輯結果。

網站、模型與依賴約 54 MB；首次下載與處理時間取決於連線、圖片大小和電腦效能。資料不送至 OCR 伺服器，沒有使用者上傳 API、追蹤碼或遙測。

## 維護與檢查

直接靜態發佈，不需要前端建置框架。開發時使用 Python 的本機 HTTP server 或其他靜態預覽工具；禁止 file:// 啟動依賴載入。

`asset-manifest.json` 記錄靜態依賴的來源、版本與 SHA256；`models/manifest.json` 記錄模型與字典 SHA256。本機開發環境另有 OCR、版面與原生可編輯 OOXML 驗證腳本，不隨網站發佈。
