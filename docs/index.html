    操作手冊

    1．加入圖片或 PDF

    點「加入圖片／PDF」可一次選取多個檔案，也能拖入檔案。截圖或複製圖片後，在頁面空白處按 Ctrl+V；多次貼上會依順序加入。正在校對文字時 Ctrl+V 會貼到文字欄。

    2．選頁與辨識

    PDF 會展開成每頁清單。勾選要處理的頁面，點「辨識選取頁面」。選取清單文字可預覽原圖。一般 PDF 優先讀取原有文字；掃描頁使用中英文 OCR。「PDF 一律重新辨識」適用於隱藏文字不正確的 PDF。處理中可按取消，已完成的結果會保留。

    3．校對辨識結果

    右側可直接修正文字。保留每行的位置可維持較好的版面；新增或刪除多行時，可使用 Word「純文字，可編輯段落」。辨識不會取回截圖看不到的公式或資料。

    4．匯出 Word、Excel、PPT

    選擇「選取頁面」或「全部頁面」後匯出。尚未辨識的頁面會先辨識。Word 預設輸出可編輯文字；「原圖版」只適合原貌備查。Excel 每頁建立工作表，表格可編輯，非表格內容會列為文字。PPT 每頁一張投影片，文字、辨識出的表格、流程形狀與可靠的圖表資料為可編輯物件；照片是獨立圖片。內嵌報表縮圖太小、縮小工程圖或圖表數字無法可靠辨識時，保留原圖並在匯出區列出需核對的區塊；請使用更清晰的截圖、原始 PDF 或原始圖檔再轉換。

    5．儲存與再次開啟

    可在支援的 Chrome／Edge 點「選擇儲存資料夾」，由你選取並授權；其他瀏覽器使用一般下載。每次匯出使用新名稱，避免覆蓋你已修改的文件。點「下載剛才的檔案」可重新下載；開啟 Word、Excel 或 PPT，請從瀏覽器下載清單或資料夾點檔案。

    6．離線與隱私

    文件內容只在你的瀏覽器處理，不上傳辨識伺服器。首次使用需要連線下載網站、模型與元件。點「準備離線使用」完成快取後，可以用同一瀏覽器再次開啟網址；瀏覽器清除快取後需要重新準備。關閉或重新整理網頁會清除目前加入的文件，請先匯出結果。
